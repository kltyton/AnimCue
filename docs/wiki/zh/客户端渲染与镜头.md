# 客户端渲染与镜头

[Wiki 首页](../Home_zh.md) | [English](../en/Client-Rendering-and-Camera.md)

客户端相关 API 位于 `com.kltyton.interactiveanimation.client.playback` 与 `com.kltyton.interactiveanimation.client.render`。

---

## `ClientScenes`

### 本地客户端预览播放

无需服务端发包，可直接在客户端游戏线程播放缺省素材或本地绑定实例：

```java
SceneHandle handle = ClientScenes.playLocal(subject, sceneId);
SceneHandle bound = ClientScenes.playLocal(subject, sceneId, Bindings.named(Map.of("prop", stack)), options);
```

### 查询客户端活跃演出状态

需要自定义镜头系统、载具渲染挂钩或碰撞接触判定的下游模组，可通过以下入口查询当前客户端场景：

- `ClientActor ClientScenes.actor(Entity entity, float partialTick)`
  若 `entity` 当前正处于某个互动场景中（主主体或参与者），返回已插值的 `ClientActor`，否则返回 `null`。
- `Entity ClientScenes.subjectFor(Entity participant, String role)`
  返回正在扮演 `role` 的 `participant` 所对应的场景主实体（例如《卓越前线：登乘演出》用于联动外侧跟拍镜头与载具接触判定）。
- `List<ClientActor> ClientScenes.extras(float partialTick, Predicate<Entity> submitted)`
  获取无需世界实体的缺省预览参与者（`item` / `block` / `model`）用于附加渲染通道。
- `ClientScene.CameraPose ClientScenes.camera(Entity player, float partialTick)`
  查询当前是否由互动场景接管 `player` 的相机姿态。

## `ClientAssets`

当参与者声明 `"type": "model"` 时，在客户端初始化阶段注册对应预览工厂：

```java
ClientAssets.registerModel("example:ritual_blade", level -> new ItemStack(ExampleItems.RITUAL_BLADE.get()));
```

工厂需返回 Minecraft 渲染管线可直接绘制的 `Entity`、`ItemStack` 或 `BlockState` 实例。

## 镜头模式（`PlaybackOptions.CameraMode`）

| 模式 | 行为说明 |
| --- | --- |
| `AUTO` | 场景编写了 `camera` 轨道时优先按轨道驱动镜头，否则对参与演出的玩家采用整体跟拍。 |
| `VANILLA` | 保持原版相机，或交由调用方模组自己的镜头控制器接管。 |
| `FOLLOW` | 即使存在 `camera` 轨道也强制使用第三人称跟随视角。 |
| `LOCKED` | 锁定相机按场景 `camera` 轨道的视角与朝向运行。 |

## 玩家骨骼、第二层皮肤与肢体弯曲

- **标准玩家骨骼与外层皮肤同步**：支持标准人形骨骼（`head`、`body` / `torso`、`left_arm`、`right_arm`、`left_leg`、`right_leg`），自动同步主体与第二层皮肤外层（`hat`、`jacket`、`left_sleeve`、`right_sleeve`、`left_pants`、`right_pants`）。
- **PAL 与 PAL More Rotation（`1.21.1`、`26.1.2`、`26.2`）**：安装 Player Animation Library 后，通过 PAL 动画层（`PalSceneLayer` / `PalScenePose`）应用玩家姿态；同时安装 PAL More Rotation 时，自动通过 `PalMoreBends` 应用躯干与四肢的多轴 `bend` 弯曲轨道。
- **1.20.1 兼容路径**：默认通过原版玩家模型通道驱动姿态，下游模组可按需将 `bend` 轨道桥接到 playerAnimator / bendy-lib。

## GeckoLib、KBR 与自定义模型渲染

- **GeckoLib 4（`1.20.1`、`1.21.1`）与 GeckoLib 5（`26.1.2`、`26.2`）**：在原生控制器取样完成后叠合互动骨骼通道，未涉及的骨骼保留原本的待机、行进、车轮或炮塔动画。
- **KBR 渲染器（`26.x`）**：检测到 KBR 附加包实体渲染器时，互动骨骼通道会在原生姿势合成之后一并应用到主体及额外几何渲染 pass。
- **自定义渲染器挂钩（`LegacyActorRenderer`）**：在 `1.20.1` 与 `1.21.1` 上，自定义实体渲染器可读取 `LegacyActorRenderer.current()` 并通过 `LegacyActorRenderer.restoreAfterDraw(Runnable)` 注册绘制后恢复回调，用于驱动非 GeckoLib 骨骼模型（如 SimpleBedrockModel 载具）。
