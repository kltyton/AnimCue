## 工程目录分层（KltytonTemple）

合拍采用「共享核心 + 按版本/加载器分层的兼容目录 + 多目标子工程」结构：

```text
AnimCue/
├── common/
│   └── src/
│       ├── main/       # 跨版本、跨加载器共享 API、资产解析、曲线插值与场景播放核心
│       └── compat/     # 按目标选装的版本/加载器适配层：
│           ├── minecraft/
│           │   ├── legacy/          # 直接渲染与 GeckoLib 4 桥接（1.20.1、1.21.1）
│           │   ├── modern/          # RenderState 渲染提交与 GeckoLib 5 / KBR 桥接（26.1.2、26.2）
│           │   ├── registry_buffer/ # RegistryFriendlyByteBuf 物品编解码（1.21.1+）
│           │   ├── pal/             # PAL 与 PAL More Rotation 动画层桥接（1.21.1、26.1.2、26.2）
│           │   ├── 1.20.1/          # 1.20.1 专用 Mixin 与预览适配
│           │   ├── 1.21.1/          # 1.21.1 专用网络与 PAL 适配
│           │   ├── 26.1.2/          # 26.1.2 专用模型渲染特性 Mixin
│           │   └── 26.2/            # 26.2 专用模型渲染特性 Mixin
│           ├── fabric/              # Fabric 入口（1.20.1、1.21.1、modern）
│           ├── forge/               # Forge 1.20.1 入口
│           └── neoforge/            # NeoForge 入口（1.21.1、modern）
├── targets/
│   ├── fabric-1.20.1/
│   ├── forge-1.20.1/
│   ├── fabric-1.21.1/
│   ├── neoforge-1.21.1/
│   ├── fabric-26.1.2/
│   ├── neoforge-26.1.2/
│   ├── fabric-26.2/
│   └── neoforge-26.2/
├── examples/           # 独立 Blockbench 美术示例（.bbmodel）与动画 JSON（不打包进发行 JAR）
├── docs/wiki/          # 中英文开发 Wiki
└── tools/blockbench/   # Blockbench 创作工具参考目录
```

## 构建任意目标

进入目标子目录运行 Gradle Wrapper 即可构建对应发行包并执行发行元数据校验：

```bash
cd targets/neoforge-1.21.1
../../gradlew build verifyDistribution
```

产物输出路径：
`targets/<loader>-<mc>/build/libs/interactive_animation-<loader>-<mc>-<version>.jar`

### 可选构建属性

- `-PanimationCompatibility=true`：在支持 PAL 的目标（`1.21.1`、`26.1.2`、`26.2`）开发运行环境中一并加载受支持版本的 PAL 与 PAL More Rotation。
- 发行包元数据中所有依赖均声明为兼容版本范围，不锁定单一精确发行版，且不通过 Jar-in-Jar 打包第三方依赖。
