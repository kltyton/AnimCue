# 示例工程与动画参考

[Wiki 首页](../Home_zh.md) | [English](../en/Examples.md)

仓库根目录下的 [`examples/`](../../../examples/README.md) 提供了完整可打开编辑的 **Blockbench 美术工程（`.bbmodel`）** 与对应导出的 **`.animation.json`** 文件，供模组开发者与动画师直接参考。

> **发行包隔离说明**：`examples/` 位于 `common/` 与 `targets/` 源码及资源树之外，**不会**被打包进任何版本的 AnimCue 发行 `.jar` 或 `-sources.jar` 中。

---

## 内置示例清单

### 1. 对决碰撞（`duel_clash`）

- **Blockbench 工程**：[`examples/duel_clash/duel_clash.bbmodel`](../../../examples/duel_clash/duel_clash.bbmodel)
- **导出动画 JSON**：[`examples/duel_clash/duel_clash.animation.json`](../../../examples/duel_clash/duel_clash.animation.json)
- **动画剪辑名**：`animation.example.duel_clash`（时长 `1.6s`）

涵盖特性：
- 主体傀儡骨架（`body` / `head` / `right_arm` / `left_arm`）+ 玩家参与者 `victim`（`minecraft:player`）。
- 参与者 `interactive_animation:root` 整体位移与 `360°` 旋转。
- 骨骼轨道的 `linear` 与 `catmullrom` 插值，以及 `right_arm_bend` 弯曲通道（`bend`）。
- 独立场景镜头轨道 `camera`（`position` 与 `rotation`）。
- 主动画 `timeline` 指令关键帧（`0.45s` 的 `"impact"` 与 `1.1s` 的 `"release"`）。
- 主动画 `sound_effects` 多音效数组（`minecraft:entity.iron_golem.attack` 带 `locator: "right_arm"` + `minecraft:block.anvil.land`）与 `particle_effects`（`minecraft:crit` 带 `pre_effect_script: "impact_burst"`）。
- 参与者独立 `sound_effects`（`minecraft:entity.player.attack.knockback`）与 `particle_effects`（`minecraft:cloud`）。

### 2. 开门穿行（`door_interaction`）

- **Blockbench 工程**：[`examples/door_interaction/door_interaction.bbmodel`](../../../examples/door_interaction/door_interaction.bbmodel)
- **导出动画 JSON**：[`examples/door_interaction/door_interaction.animation.json`](../../../examples/door_interaction/door_interaction.animation.json)
- **动画剪辑名**：`animation.example.open_door`（时长 `1.4s`）

涵盖特性：
- 以门框为基准的 `door_leaf` 合页摆动（`catmullrom` 平滑旋转）。
- 参与者 `actor`（`minecraft:player`）走向门前并穿过门洞的整体位移与四肢摆动。
- `timeline` 事件（`"door_open"`、`"step_through"`）、`sound_effects`（`minecraft:block.iron_door.open`）及简写型 `particle_effects`（`"minecraft:crit"`）。

## 使用流程

### 在 Blockbench 中打开编辑

1. 在 Blockbench `5.0.0+` 中安装 **AnimCue Studio** 插件（使用仓库 [`tools/blockbench/dist/animcue_studio.js`](../../../tools/blockbench/dist/animcue_studio.js) 或从 Blockbench 插件商店安装）。
2. 直接打开上述 `.bbmodel` 文件，即可在左侧大纲、时间轴及特效轨道（`timeline` / `sound` / `particle`）中查看完整关键帧布局。
3. 可随时修改动作并通过面板 **导出**（或 **文件 → 导出 → 合拍动画...**）重新生成 `.animation.json`。

### 在模组代码中接入

将所需的 `.animation.json` 放入**你自己的模组**资源目录下（例如 `assets/mymod/animations/duel_clash.animation.json`），初始化注册后触发播放：

```java
// 1. 在模组公共初始化阶段注册动画文件
InteractiveScenes.register(MyMod.class, "mymod:animations/duel_clash.animation.json");

// 2. 在服务端触发播放并按需自定义标记、音效或粒子处理
var sceneId = new SceneId("mymod:animations/duel_clash.animation.json", "animation.example.duel_clash");
var subject = SceneSubject.entity(bossEntity);
var bindings = Bindings.named(Map.of("victim", targetPlayer));

var options = PlaybackOptions.DEFAULT
        .markers(marker -> {
            if ("release".equals(marker.instruction())) {
                marker.playback().useWorldCoordinates("victim");
            }
        })
        .sounds(kf -> {
            // 可选拦截：若省略 .sounds(...)，合拍会自动在对应坐标播放已注册音效
            SceneEffects.playSound(level, kf);
        })
        .particles(kf -> {
            // 可选拦截：若省略 .particles(...)，合拍会自动生成对应粒子
            SceneEffects.spawnParticle(level, kf);
        });

InteractiveScenes.play(subject, sceneId, bindings, options);
```
