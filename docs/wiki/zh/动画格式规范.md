# 动画格式规范（`interactive_animation:interactions`）

[Wiki 首页](../Home_zh.md) | [English](../en/Animation-Format.md)

合拍（AnimCue）通过在标准 Bedrock / GeckoLib / PAL 动画 JSON（`format_version: "1.8.0"`）顶层添加 `interactive_animation:interactions` 字段来描述多参与者互动场景。不包含 `interactive_animation:interactions` 的普通动画文件不受影响。

## 顶层结构

```json
{
  "format_version": "1.8.0",
  "animations": {
    "<动画名称>": {
      "animation_length": 2.0,
      "bones": { ... },
      "timeline": {
        "0.25": "marker_a",
        "1.00": ["marker_b", "marker_c"]
      }
    }
  },
  "interactive_animation:interactions": {
    "<动画名称>": {
      "participants": [ ... ],
      "camera": { ... }
    }
  }
}
```

### 解析校验规则（`SceneReader`）

- `interactive_animation:interactions` 下的每个键名必须在 `animations` 中存在同名主动画。
- 每个场景必须在 `participants` 中声明 **1 至 64** 个参与者。
- 每个参与者的 `role` 必须为非空字符串且在同一场景内唯一。
- 若主动画声明了 `animation_length`，任何骨骼轨道、镜头轨道、`timeline`、`sound_effects` 或 `particle_effects` 的时间戳都不得超出 `animation_length`（允许误差 `1e-5`）；若未声明，则自动取所有轨道与关键帧的最大时间。

---

## 参与者（`participants`）

`participants` 数组中的每一项包含以下字段：

| 字段 | 必填 | 类型 | 说明 |
| --- | :---: | --- | --- |
| `role` | 是 | `string` | 场景内唯一角色名，供 `Bindings.named(...)`、`SceneHandle` 及 `ClientScenes.subjectFor(...)` 引用。 |
| `type` | 否 | `string` | 缺省预览素材类型，可选 `entity`、`item`、`block`、`model`（缺省为 `model`，大小写不敏感）。 |
| `id` | 是 | `string` | 缺省素材的资源 ID（如 `minecraft:player`、`minecraft:iron_sword`，或通过 `ClientAssets.registerModel` 注册的自定义模型 ID）。 |
| `bones` | 否 | `object` | 骨骼名 → 通道轨道（`position`、`rotation`、`scale`、`bend`）的映射。 |
| `sound_effects` | 否 | `object` | 按时间触发的声音关键帧（写法同主动画 `sound_effects`，回调中 `role` 为当前参与者名）。 |
| `particle_effects` | 否 | `object` | 按时间触发的粒子关键帧（写法同主动画 `particle_effects`，回调中 `role` 为当前参与者名）。 |

播放时通过 `Bindings` 传入的世界实体、物品栈或方块状态会自动覆盖缺省素材。

---

## 整体轨道 `interactive_animation:root`

保留骨骼名 `interactive_animation:root` 用于驱动整个参与者相对于主场景锚点（`SceneSubject.Frame`）的整体位移与旋转：

- **`position`**：采用模型单位（**16 单位 = 1 格**），并随主场景 `yaw` 旋转变换到世界空间。
- **`rotation`**：单位为**度（degrees）**。保留作者编排的旋转圈数，不截断到 `[-180, 180]`，支持多圈翻滚（例如 `0` → `720`）。
- **`scale`**：可选缩放向量（默认 `[1, 1, 1]`）。

未编写 `interactive_animation:root` 的参与者仍可正常播放骨骼姿态轨道，同时不改写实体在世界中的位移。

---

## 骨骼通道与插值（`BoneTrack` / `AnimationCurve`）

每个骨骼可按需包含以下四个通道：

- `position`（默认 `[0, 0, 0]`）
- `rotation`（默认 `[0, 0, 0]`）
- `scale`（默认 `[1, 1, 1]`）
- `bend`（默认 `[0, 0, 0]`，供 PAL More Rotation 或 1.20.1 弯曲桥接读取肢体/躯干弯曲角）

### 关键帧写法

每个通道支持：
- 静态 3 元数值数组 `[x, y, z]` 或单个标量数值（自动展开为 `[v, v, v]`）；
- 单个带 `pre` / `post` 的关键帧对象；
- 按秒计时的时间戳字典（`"0.0"`、`"0.25"` 等，必须为有限非负数）。

关键帧支持不连续的 `pre` / `post` 以及 `lerp_mode` 插值模式：

```json
"left_leg": {
  "rotation": {
    "0.0": [-30, 0, 0],
    "0.25": {
      "post": [28, 0, 0],
      "lerp_mode": "catmullrom"
    },
    "0.5": [-30, 0, 0]
  },
  "bend": {
    "0.0": [18, 0, 0],
    "0.25": {
      "post": [64, 0, 0],
      "lerp_mode": "catmullrom"
    },
    "0.5": [18, 0, 0]
  }
}
```

支持的 `lerp_mode` 取值：
- `"linear"`（默认）：在上一帧 `post` 与下一帧 `pre` 之间线性插值。
- `"catmullrom"`：基于相邻控制点的 Catmull-Rom 三次样条平滑插值。

所有通道分量必须为有限数值（`interactive_animation:interactions` 轨道不解析 Molang 字符串表达式）。

## 镜头轨道（`camera`）

与 `participants` 同级可声明可选 `camera` 对象，直接采用 Bedrock `position` 和 `rotation` 通道：

```json
"interactive_animation:interactions": {
  "animation.example.intro": {
    "participants": [ ... ],
    "camera": {
      "position": { "0.0": [0, 28, -48], "1.5": [16, 24, -40] },
      "rotation": { "0.0": [12, 0, 0], "1.5": [8, -20, 0] }
    }
  }
}
```

当播放选项使用 `PlaybackOptions.CameraMode.AUTO` 时，存在 `camera` 轨道会优先启用该镜头，否则对参与演出的玩家自动采用平滑跟拍。

## 时间轴事件（`timeline`、`sound_effects`、`particle_effects`）

主动画中的 `timeline` 会在对应时刻触发 `PlaybackOptions.Marker` 回调。每个时间戳支持单条指令字符串或字符串数组：

```json
"timeline": {
  "0.16": "door_open",
  "0.85": ["settle", "mount"]
}
```

主动画或单个 `participants` 条目也可直接编写标准 Bedrock / GeckoLib 风格的 `sound_effects` 与 `particle_effects`（每个时间戳支持对象、数组或直接简写为效果 ID 字符串）：

```json
"sound_effects": {
  "0.25": {
    "effect": "minecraft:entity.experience_orb.pickup",
    "locator": "mouth"
  },
  "0.80": "minecraft:block.anvil.land"
},
"particle_effects": {
  "0.40": {
    "effect": "minecraft:crit",
    "locator": "right_hand",
    "pre_effect_script": "slash"
  }
}
```

未覆盖回调时，非原生主轨道及所有参与者轨道上的已注册原版／模组音效与粒子会自动在对应坐标播放（原动画 `nativePlayback = true` 的主轨道仍交由 GeckoLib 等原生控制器触发，避免重复播放）。当同环境安装了 Kltyton Bedrock Runtime（`kltyton_bedrock_runtime`，兼容 Lite 与完整版）时，默认粒子关键帧还会自动兼容播放 KBR `particle_definitions/*.json` 中的暴雪 Billboard 粒子与 3D 模型粒子，并传递 `pre_effect_script` / `script` MoLang 初始化表达式。
