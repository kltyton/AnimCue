# AnimCue 合拍插件

用于制作 **AnimCue** 多角色互动动画的 Blockbench 插件，支持桌面版和网页版（5.0.0+），界面语言跟随 Blockbench 设置自动切换中英文。

[English](README.md)

## 安装

1. 打开 Blockbench，进入 **文件 → 插件**。
2. 点击 **从文件加载插件**，选择 [dist/animcue_studio.js](dist/animcue_studio.js)。
3. 如需给玩家做肘/膝/躯干弯曲，建议同时安装 **PAL Bend Player Tools**（0.4.2+），两个插件会自动联动。

## 用法

1. 打开主体模型（`.bbmodel`），或从 **文件 → 新建 → 合拍场景 (AnimCue)** 创建空白场景。
2. 在左侧 **合拍场景** 面板点 **+** 添加角色：
   - `.bbmodel` 或 Bedrock `.geo.json`（可顺手选贴图）
   - 内置 **PAL 弯曲玩家** / **PAL 龙核玩家**（装了 PAL 插件后可直接添加）
   - **原版实体模板**
   如果主体本来是单贴图格式，第一次添加角色会自动建一个多贴图副本，避免贴图互相覆盖。
3. 双击角色行（或点移动图标）会自动切到动画模式第 0 帧并选中角色根组，直接在视口拖位置即可。
   - 根组管整体移动和转身（导出为 `kltyton:root`）。
   - 子骨骼和 PAL 的 `*_bend` 骨骼管肢体动作与三轴弯曲。
   - 点角色行右侧 **⋮** 可以调整绑定顺序、把现成 PAL / Emote / 龙核 / 基岩动画直接导到这个角色身上、复制或移除。
4. 点工具栏相机图标可添加镜头轨道并随时预览当前帧镜头视角；点旗标图标在当前时间插事件标记。
5. 点面板右上角导出图标（或 **文件 → 导出 → 合拍动画**）输出 `.animation.json`；点导入图标或直接用原生导入加载已有合拍动画即可继续编辑。

## 打包

```bash
node build.cjs
```
